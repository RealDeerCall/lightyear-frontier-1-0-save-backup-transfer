## 🛠️ Troubleshooting

### Windows says the destination path is too long
Extract the release to a short path such as `C:\Tools\lf1-save` instead of unpacking it inside several nested folders.

### The EXE does not start
Make sure the ZIP was fully extracted first. Do not run the executable directly from inside the compressed archive. Close the game and try launching the executable again from the extracted folder.

### The game still shows the same symptom
Restart Windows, launch the utility again, follow the steps in order, and then retest the same game scenario. Also confirm that the game itself is updated to the build you intend to use.

### Windows Security shows a prompt
Review the file name, release hash and repository source before choosing how to proceed. The SHA-256 values above can be used to confirm that the downloaded release matches this repository entry.
